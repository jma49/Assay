# 审批流程

非管理员的变更要等人审核，这样没有人能悄悄改变一个检查的行为。

## 哪些变更需要审批

| 变更 | 管理员 | 其他人 |
|---|---|---|
| 创建检查 | 立即生效 | 需要审批 |
| 修改自己的检查 | 立即生效 | 立即生效 |
| 修改别人的检查 | 立即生效 | 需要审批 |
| 删除检查 | 立即生效 | 需要审批 |

项目经理和管理员可以审批或驳回。

## 如何审核

打开侧边栏里的**审批**。**待审批**列出每个请求的申请人、时间、检查和备注，点 **Approve**（通过）或 **Reject**（驳回）并写上意见。**审批历史**保留所有决定。
