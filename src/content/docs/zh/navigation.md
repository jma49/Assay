# 界面导航

左侧的**侧边栏**用来切换 Assay 的各个部分，顶部的**顶栏**显示当前页面，以及这个页面的操作。

## 侧边栏

侧边栏分为**监控**和**工作区**两组。

| 项目 | 用途 |
|---|---|
| **检查** | 所有检查的当前状态：出错的在前，其次是有问题的，最后是正常的；显示与上次相比的变化和趋势。点进一个检查可以看最新结果（新增 / 仍未解决 / 已修复的行）、执行历史、查询和定时。在检查页面点 **编辑** 会打开**管理检查**，在那里修改标签、范围和查询。 |
| **动态** | 发生了什么变化：哪些检查出错、发现问题、出现新增行或恢复正常，以及每条告警发到了哪里 |
| **执行记录** | 所有执行，最新的在最上面，带状态统计和执行按钮 |
| **覆盖情况** | 数据库里哪些表已经有检查在盯着 |
| **分析** | 结果随时间的变化 |
| **审批** | 等待审核的变更（管理员和经理可见） |
| **通知** | 告警发到哪里：Slack、Discord、Telegram、飞书、企业微信或 Webhook（见 [通知](/docs/notifications)） |
| **API 密钥** | 供 AI 代理通过 MCP 使用 Assay 的个人密钥（见 [API 密钥与 MCP](/docs/api-keys)） |
| **成员** | 谁有访问权限、是什么角色（仅管理员可见） |
| **文档** | 就是这些页面 |

没有权限的项目不会显示。侧边栏底部是你的账号、语言切换和深色模式切换。在手机上，侧边栏会变成顶部的一行。

## 顶栏

左边是页面标题，右边是这个页面自己的控件：搜索、筛选、执行记录页的 **执行检查…** 等。如果你有编写检查的权限，最右边始终有 **新建检查**。

## 键盘

- 在**管理检查**里，**↑** 和 **↓** 在检查列表中移动，**Home** 和 **End** 跳到首尾，**回车** 打开选中的检查进行编辑。
- 在**覆盖情况**里，同样的方向键和 **Home** / **End** 在表的列表中移动。
- 在文档搜索框里，**↑** 和 **↓** 在搜索结果中移动，**回车** 打开选中的结果。
