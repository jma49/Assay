# 账号与角色

## 注册

任何人都可以用邮箱或 Google 注册。新账号的角色是**查看者**，管理员之后可以在[用户](/docs/managing-users)里给它更多权限。

自托管的工作区可以用 `ALLOWED_EMAIL_DOMAINS` 限制只有公司邮箱能注册（见[环境变量](/docs/environment-variables)）。

## 角色

| 权限 | 查看者 | 开发者 | 项目经理 | 管理员 |
|---|:-:|:-:|:-:|:-:|
| 查看检查和结果 | ✓ | ✓ | ✓ | ✓ |
| 创建和编辑检查 | | ✓ | ✓ | ✓ |
| 执行检查 | | ✓ | ✓ | ✓ |

| 分配开发者和查看者角色 | | | ✓ | ✓ |
| 分配任意角色、管理用户 | | | | ✓ |
| 清理缓存和系统维护 | | | | ✓ |

## 公开演示

工作区设置了 `DEMO_MODE=true` 时，查看者还可以执行种子数据里的示例检查（每小时最多 20 次），让访客亲眼看到检查怎么发现问题。他们仍然不能执行别人的检查，也不能修改任何内容。

## 需要审批的变更

管理员的变更立即生效。其他人创建检查、修改别人的检查、删除检查，都要等审批；修改自己的检查不用。详见[审批流程](/docs/approvals)。
