# 数据分析

侧边栏里的**分析**展示检查随时间的执行情况。

## 筛选

- **时间范围**：最近 7、30、90 天，或全部时间。按你所在的时区计算日期。
- **检查**：单个检查或全部。
- **标签**：只看带所选标签的检查。

## 能看到什么

- **统计**：执行次数，以及结果为**出错**、**有问题**、**正常**的次数和各自所占比例。
- **执行结果**：用图表展示同样的比例。
- **每日执行**：时间范围内每一天的全部执行和各结果的次数，用来发现开始出问题的检查。
- **按天**：最近的若干天（最多 14 天），最新的在前。
- **按检查**：每个检查各结果的次数、正常率（没有发现问题的执行所占比例）和最近一次执行的时间。
