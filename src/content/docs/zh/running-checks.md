# 执行检查

执行检查需要开发者或更高角色。

## 执行一个检查

1. 打开仪表盘。
2. 在**手动执行检查**里保持 **Execute Selected Script**，选择检查。可以按名称或 `#标签` 搜索。
3. 点 **Run Check**。

执行完成后，结果会出现在**执行历史**里。

## 一次执行多个

选 **Bulk Execution**，再选 **Execute All Scripts**（全部）或 **Execute Scheduled Scripts**（只执行打开了定时的检查）。进度面板会逐个显示每个检查的执行情况。

菜单栏也有这两个入口：在任何页面选 **文件 → 执行检查…** 或 **文件 → 批量执行…**，都会打开仪表盘并切到对应模式。

## 限制

每个检查都在只读事务里执行，30 秒后取消（看起来会跑很久的查询是 5 分钟）。被取消的检查记为**失败**。
