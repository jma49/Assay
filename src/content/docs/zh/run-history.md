# 执行历史与结果

## 执行历史

仪表盘列出所有执行记录，最新的在最上面。你可以：

- 用顶部四个数字卡片（全部执行、通过、需关注、失败）按状态筛选，或在菜单栏用 **显示 → 通过 / 需关注 / 失败**；再点一次当前卡片取消筛选；
- 按检查名称、信息或 `#标签` 搜索；
- 按名称或时间排序；
- 翻页查看更早的记录。

时间按你所在的时区显示，一周内显示为“3 小时前”这样的相对时间；鼠标悬停可看到精确时间。

要看某一个检查的历史，打开**脚本**，点 **执行历史**。

## 完整报告

点击一条记录打开详情：

- 状态、时间和信息；
- **需关注**时，列出查询返回的每一行，可以 **导出 CSV**；
- **再次执行** 立即重新执行这个检查并打开新结果，修完数据后用来确认；
- 开启 AI 后，失败和需关注的记录上有 **AI 分诊**（见 [AI 助手](/docs/ai-assistant)）。

## 键盘操作

在脚本窗口里，**↑** 和 **↓** 在列表中移动，**Home** 和 **End** 跳到首尾，**回车** 打开选中的检查进行编辑。**覆盖情况** 里的表列表用同样的按键。
