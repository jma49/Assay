# 执行历史与结果

## 执行历史

仪表盘列出所有执行记录，最新的在最上面。你可以：

- 用 **All**、**Success**、**Attention**、**Failure** 按状态筛选，或在菜单栏用 **显示 → 通过 / 需关注 / 失败**；
- 按检查名称、信息或 `#标签` 搜索；
- 按名称或时间排序；
- 翻页查看更早的记录。

要看某一个检查的历史，打开**脚本**，点它的历史按钮。

## 完整报告

**View Full Report** 打开单次执行的详情：

- 状态、时间和信息；
- **需关注**时，列出查询返回的每一行；
- **失败**时，显示错误，并有一个 **AI** 按钮来解释错误、给出修复建议。
