# 菜单栏与 Dock

Assay 借用了 Mac OS X 的布局：底部的 **Dock** 负责「去哪里」，顶部的**菜单栏**负责「做什么」。

## Dock

| 图标 | 打开 |
|---|---|
| 仪表盘表盘 | 仪表盘 |
| 数据库 | 脚本 |
| 带 + 的数据库 | 新建检查 |
| 饼图 | 数据分析 |
| 绿色对勾 | 审批 |
| 人像 | 用户 |

图标下方的小三角表示你当前所在的位置。用键盘时，按 **Tab** 移到 Dock，再用 **← →**、**Home**、**End** 在图标之间移动。

## 菜单栏

| 菜单 | 命令 |
|---|---|
| **Assay** | 关于 Assay、外观（浅色、深色、跟随系统）、语言、退出登录 |
| **文件** | 新建检查、执行检查…、批量执行…、执行历史 |
| **显示** | 显示全部、通过、需关注或失败的结果；重新载入 |
| **窗口** | 收起或展开窗口、缩放 |
| **帮助** | 本文档、GitHub、报告问题 |

属于仪表盘的命令（比如筛选执行历史），在其他页面使用时会先打开仪表盘。

## 窗口

窗口左上角的红、黄、绿三个按钮分别是：关闭（回到首页）、收起到只剩标题栏、缩放到屏幕全宽。双击标题栏也可以收起窗口。
