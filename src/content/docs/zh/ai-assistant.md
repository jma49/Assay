# AI 助手

工作区设置 `AI_ENABLED=true` 后，可以使用三个助手；否则这些按钮不会显示。请求经由 Vercel AI Gateway 发出，首选模型不可用时会自动切换到备用模型。

| 功能 | 位置 | 谁可以用 |
|---|---|---|
| **生成 SQL** | 编辑器工具栏 **AI** | 开发者及以上 |
| **解释 / 优化 SQL** | 编辑器工具栏 **AI** | 开发者及以上 |
| **解释错误** | 失败记录的完整报告 | 所有人 |

AI 能看到你的问题、SQL 和数据库的表结构，看不到数据本身。

## 生成 SQL 如何自检

生成 SQL 起草的是一个完整的检查，而不只是一条查询。查询进入编辑器之前，Assay 会：

1. 像其他检查一样做校验，所以它不能写数据；
2. 在只读事务里试运行一次（超时 10 秒），统计它当前会标出多少行；
3. 如果试运行失败，把数据库错误交回模型，修复一次。

通知会告诉你这个检查当前标出多少行，或者试运行仍然失败的原因。

## 限制

为了让成本可控，每人每小时最多 **30 次** AI 请求。描述最长 2,000 字符，SQL 最长 20,000 字符，错误信息最长 4,000 字符。

> AI 写的 SQL 保存前一定要读一遍。它和其他检查一样会经过校验，所以依然不能写数据。
