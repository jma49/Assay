# 用户与权限

管理员（以及只分配开发者、查看者角色时的项目经理）在 Dock 里的**用户**中分配角色。

## 给某人分配角色

1. 对方先注册，初始是查看者。
2. 在**用户**里点 **Add user role**。
3. 填写对方的用户 ID（以 `user_` 开头）和邮箱，选择角色。

之后要改角色，在列表里直接选新角色；**Remove role** 会移除角色。

## 规则

- 项目经理只能分配开发者和查看者，也不能修改管理员或其他项目经理的角色。
- 只有管理员能修改自己的角色。
- 每个用户显示的邮箱来自其账号本身，而不是填写的内容。

自托管的工作区，第一个管理员在命令行里设置：

```bash
npm run user:set-role -- you@example.com admin
```
