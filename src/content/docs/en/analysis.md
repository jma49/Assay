# Analysis

**Analysis** in the sidebar shows how your data quality changes over time.

## Filters

- **Time range** — the last 7, 30 or 90 days, or all time.
- **Script** — one check or all of them.
- **Tags** — only checks with the chosen tags.

## What you see

- **Totals** — runs, success rate, and how many failed or need attention.
- **Distribution** — the share of each status.
- **Trend** — runs per status over recent days, to spot a check that started failing.
